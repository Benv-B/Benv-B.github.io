# Yoma - 面向嵌入式工程师的专门 Agent

我是一名嵌入式软件工程师，日常高强度使用 Claude Code、Codex、Cursor 写代码，比如说应用层、改驱动、搭框架。单纯就写代码来说，它们效果很好，往往也能符合要求。但嵌入式是面对硬件的，一遇到和现实硬件相关的部分，通用 agent 就非常吃力，耗时长、效率低、做出来的东西也不符合要求，比如说：

- 读原理图，知道元器件与芯片之间的连接关系，一些关键电路作用
- 阅读大几千页手册，某个外设的寄存器到底该怎么配，通信协议是怎么样子
- 打断点，看日志，分析堆栈调用，判断板子跑到哪
- 如果通信总线挂了，还得长时间采日志，甚至接上逻辑分析仪看协议时序是否正确

就读手册和原理图（大部分都是PDF），GPT、Claude 往往靠切图识别，上下文消耗很大，又慢又贵。DeepSeek 这种几乎没有识图能力的模型，完全无能为力。

所以我做了 Yoma：按嵌入式工程师的习惯，原生集成了读取原理图、数据手册、烧录、读取分析日志、自动使用GDB 和解析逻辑分析仪协议等嵌入式特定工具，而且不依赖多模态模型，DeepSeek也能读取手册、原理图。

---

## Yoma 原生集成嵌入式专门工具：

- **netlist** ： 原理图识别工具，支持读 Altium Smart PDF 或与网表（`.net`），获取元器件型号和连接信息与关键电路信息。
- **datasheet**：快速准确地获取上千个芯片信息。问哪个芯片的相关信息，不需要重新丢给AI一本很长的手册进行耗时耗token的解析阅读，yoma可以直接从数据库里抽出相关原文，带着手册页码，保证准确符合原文事实。不用通读几千页，也不会把相似型号的寄存器搞混。而 Codex / Claude 要么靠幻觉知识，要么使用切图把 PDF 塞进窗口进行图片识别，又慢又贵；Yoma 使用 DeepSeek 也能查。
- **flash**：烧录工具，支持 OpenOCD、J-Link、CubeProgrammer、esptool 等，并记住烧录固件的版本。
- **log**：日志采集工具，支持串口或 RTT，支持长时间采集大量日志，不打乱模型上下文信息，避免把上下文窗口撑爆。
- **gdb**：调试工具，能打断点、单步调试、看变量和调用栈，判断板子跑到哪。程序跑飞了，也能看出卡在哪。当日志信息不明确的时候，可以直接看硬件寄存器现场。
- **la**：逻辑分析仪工具，把 I²C / SPI / UART 总线上实际波形解析出来，验证通信时序。

原理图不需要识别图片读取，对于DeepSeek 这种不认图的模型也能用。如果有硬件源工程的话，发送 `.net` 文件效率更高。

## 符合嵌入式开发习惯：新项目不从空白开始

对于基于 STM32 芯片的硬件，嵌入式工程师通常不会手写 RCC 和 GPIO 等基础外设的初始化代码，而是使用 CubeMX 配置外设，一键生成驱动代码、中间件代码（比如 freertos 等），再在能 blink 的基础上添加自己的逻辑。

比起当年手动计算十六进制数配置寄存器，图形化配置是方便了，可那是十几年前的进步。每个配置栏是什么意思，怎么配置，仍要翻手册，这个过程实在是费时费力；要是同时配置多个外设，引脚冲突了之后又要再翻一遍手册解决冲突。但最后配置的时候，真正用到的知识可能是以及阅读过的手册的十分之一。都 2026 年了，这种事不该再靠工程师检索，这是 AI 最擅长的。

所以 Yoma 开发了「AI 化的 CubeMX」，不是「让模型手写一份 HAL 库」：

1. 把原理图（PDF 或 `.net`）和需求交给它，比如要驱动电机、要用这片 SPI Flash、要用这个元器件做震动检测。
2. 它从原理图识别元器件型号和连接关系，自动从数据库读芯片使用的通信协议与配置约束。
3. 写出配置文档，自主用工具校验、生成一份能直接编译烧录的基本驱动框架。
4. 再在这份能跑的骨架上改产品逻辑。

模型不直接写驱动代码。让 AI 手写消耗上下文、容易出现幻觉、还难以复用。但使用工具生成的工程，效率和可靠性都增加了。

而对于 ESP32、Nordic 这类没有图形化配置工具的芯片，一般是先找一个和需求接近的例程，比如蓝牙连接、Wi-Fi，把例程跑通之后，再深度定制自己的固件，往上加功能组件。Yoma 同样遵循这个习惯：数据库里不只有数据手册，还有 codelib，囊括了嵌入式常用的许多例程库，像 FreeRTOS、LVGL、cJSON、lwIP、Mbed-TLS 等，能自主按需要把该用的库集成、移植进工程。

## 用硬件上的证据来验收

改完程序、编译通过、烧上去，Yoma 能依据日志和 gdb 把调试跑完；如果遇到了总线挂了再上逻辑分析仪。用硬件的第一手信息验证功能，避免因为幻觉来回返工。
